# Task 1 report: profile ownership and sync ledger

## Status

COMPLETE. The persistence boundary now uses `Profile` as the only ownership root. Existing learner UUIDs and timestamps are preserved, all learning records use `profileId`, and the idempotent sync ledger models are available.

## Changes

- Renamed the Prisma `Learner` model/table to `Profile` and added ordered backfilled names.
- Renamed `learnerId` ownership columns to `profileId` on `StudySession`, `EvidenceEvent`, `MasterySnapshot`, and `LessonProgress`.
- Added `Device`, `SyncMutation`, and `SyncChange` models with profile indexes and cascade ownership.
- Added migration `prisma/migrations/20260712090000_profiles_and_sync/migration.sql` with UUID/timestamp-preserving backfill and constraints.
- Updated domain plans, mastery/evidence types, repositories, API routes, and browser hooks to use profile terminology.
- Added `createProfile`, `listProfiles`, `listProfileSessions`, `recordMutation`, and `countMutations` in `src/server/profile.ts`.
- Added profile isolation and replay-idempotency coverage in `src/server/profile.test.ts`; updated existing integration/unit contracts.
- Kept compatibility aliases for public-demo cookie helpers and log helper names while routing all persistence through profiles.

## Review fixes (2026-07-12)

The Task 1 review findings are resolved:

- `resolvePublicProfileId()` now checks the historical `nawa_learner_id` (`LEARNER_COOKIE`) before issuing a new profile cookie, then promotes that UUID to `nawa_profile_id` without changing ownership IDs. The learner helper aliases remain available for existing callers.
- `scripts/verify-isolation.mts` now uses `ensureProfile`, `profileId`, `plan.profileId`, and `db.profile` cleanup throughout.
- `recordMutation()` now returns an existing row only when both `profileId` and `deviceId` match. Replays from another profile or device throw `Mutation ID already belongs to another profile or device`, including a concurrent unique-ID race.
- `createProfile()` trims names and rejects blank input with `Profile name is required`; it no longer silently creates a generic profile.
- Added regression coverage for legacy-cookie promotion, mutation ownership mismatch, and blank names.
- `git diff --check` reports no whitespace errors.
